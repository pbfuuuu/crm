# CRM для аренды помещений

Веб-система учёта арендаторов торгового центра / офисного здания: клиенты, помещения,
договоры, оплаты по месяцам, долги. Python 3.10+, Flask, SQLite.

## Запуск

```bash
python -m venv venv
venv\Scripts\activate          # Windows
source venv/bin/activate       # Linux / macOS

pip install -r requirements.txt

python manage.py create-admin  # создаст администратора и покажет временный пароль
python run.py                  # откройте http://127.0.0.1:5000
```

Просмотр готовой системы (демо); Вместо `create-admin`:

```bash
python manage.py seed-demo     # вымышленные клиенты, договоры, оплаты, 2 пользователя
```

Пароли выводятся в консоль один раз. При первом входе система потребует задать свой.

## Что умеет

| Раздел | Возможности |
|---|---|
| Клиенты | добавить, изменить, удалить (только админ), поиск, фильтр «с долгом». ИНН хранится зашифрованным |
| Помещения | добавить, изменить, удалить (только админ), фильтры по статусу и этажу |
| Договоры | оформление (помещение автоматически «занято»), продление, расторжение, **смена арендной платы с историей** |
| Оплаты | таблица «кто оплатил за месяц», частичные оплаты, остаток, выгрузка в Excel |
| Должники | долг по каждому договору, выгрузка в Excel |
| Пользователи (админ) | создание с автоматическим паролем, сброс пароля, блокировка |
| Журнал (админ) | кто, что и когда изменил |

Роли: **администратор** - всё; **менеджер** - всё, кроме удаления, пользователей и журнала.

## Резервная копия

```bash
python manage.py backup        # копия базы в папку backups/
```
Не забывайте копировать и `instance/fernet.key` (хранить отдельно от базы).

## Тесты

```bash
python -m unittest discover -s tests -t .
```

## Структура

```
run.py              запуск
manage.py           служебные команды (create-admin, seed-demo, backup, init-db)
seed.py             демонстрационные данные
app/
  __init__.py       создание приложения
  config.py         настройки, ключи
  db.py, schema.sql подключение к SQLite и описание таблиц
  security.py       пароли, шифрование, проверка ИНН, CSRF, заголовки
  services.py       деньги, даты, начисления и расчёт долга
  auth.py           вход, выход, смена пароля, права доступа
  tenants.py  premises.py  contracts.py  payments.py  reports.py  users.py  journal.py
  templates/        HTML-страницы (Jinja2)
  static/           стили и крошечный скрипт подтверждения удаления
tests/              автоматические тесты
```
